## Overview

       width="900"/>

Linux commands are the foundation of Linux system administration and are used daily by IT professionals to navigate directories, manage files, search data, and control file permissions. In this practical, you will perform hands-on exercises using commonly used Linux commands such as `pwd`, `ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`, `grep`, and `chmod`. These commands are essential for Linux Administration, Cybersecurity, DevOps, Cloud Computing, and IT Support roles.

---

## Learning Objectives

After completing this practical, you will be able to:

- Understand the Linux terminal environment.
- Navigate the Linux file system using basic commands.
- Create and manage directories and files.
- Copy, move, rename, and remove files.
- Search text within files using `grep`.
- View and understand file permissions.
- Modify file permissions using `chmod`.
- Understand how these commands are used in real-world system administration.

## Key Takeaways

- Linux commands are the primary method of interacting with Linux servers.
- The `pwd` command displays the current working directory.
- The `ls` command lists files and directories with multiple viewing options.
- The `cd` command is used to navigate through the Linux file system.
- `mkdir` creates directories for organizing files.
- `touch` creates new empty files.
- `cp` copies files while preserving the original.
- `mv` moves or renames files and directories.
- `rm` permanently removes files.
- `grep` efficiently searches for specific text inside files.
- `chmod` controls file access permissions for users, groups, and others.
- These commands are used daily by Linux Administrators, System Administrators, DevOps Engineers, Cloud Engineers, and Cybersecurity Professionals.
